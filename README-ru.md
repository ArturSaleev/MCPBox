# MCPBox

MCPBox - это control plane на Go для MCP-серверов. Он позволяет группировать локальные и удаленные MCP-бэкенды по проектам, смотреть что они публикуют, отслеживать трафик и отдавать один project URL для Claude, Cursor, Codex, LM Studio и локальных сценариев с Ollama.

## Зачем Нужен MCPBox

Когда MCP-серверов становится много, все быстро превращается в набор JSON-конфигов, терминалов и локальных костылей. MCPBox собирает это в один бинарник и одну встроенную панель управления.

Основные возможности:
- Организация локальных `stdio` и удаленных `HTTP streaming` MCP-серверов по проектам
- Единый project endpoint `/mcp/{project_token}`, который агрегирует все включенные серверы проекта
- Встроенная База знаний / RAG-коллекции с локальной индексацией кода, текста, CSV, XLSX, DOCX, PPTX и PDF с текстовым слоем
- Live inspection локальных `stdio` серверов: `tools`, `resources`, `prompts` и соседний README
- Health-check при создании, редактировании, ручной проверке и запуске локального сервера
- Audit log для MCP-трафика и управляющих действий
- Пауза проекта и включение или отключение отдельных серверов
- Встроенный Market / Catalog для синхронизации, установки, проверки и удаления интеграций
- Запуск локального `ollama + MCPBox` в один клик через встроенный `mcphost/sdk`
- Один бинарный файл со встроенным React UI и локальной SQLite-базой

- Агрегированный project endpoint теперь пишет явные audit-события для `tools/list`, `tools/call`, `resources/list`, `resources/read`, `prompts/list` и `prompts/get`
- Health-check стал заметно глубже и для локальных `stdio`, и для удаленных `HTTP streaming` серверов: после `initialize` MCPBox проверяет list-методы и при необходимости запускает безопасный probe, например SQL-проверку или просмотр директории

- Очистка registry при остановке стала безопаснее: остановленные runner'ы удаляются из in-memory registry, а не остаются висеть
- Экран Market теперь автоматически запускает sync при открытии, поэтому каталог чаще заполняется без лишнего ручного шага

## Быстрый Старт

1. Скачайте бинарник для своей ОС из последнего релиза или соберите проект из исходников.
2. Запустите `MCPBox`.
3. Откройте `http://127.0.0.1:38180/`, если браузер не открылся автоматически.
4. Создайте проект.
5. Добавьте локальные `stdio` серверы или удаленные `HTTP streaming` серверы.
6. Скопируйте project endpoint из UI и подключите AI-клиент к `/mcp/{project_token}`.

Для локального тестирования через Ollama:
1. Убедитесь, что `ollama` установлена.
2. Откройте проект, в котором есть хотя бы один включенный MCP-сервер.
3. Выберите локальную модель Ollama в UI.
4. Нажмите `Launch Ollama`.

Для LM Studio:
1. Откройте проект, в котором есть хотя бы один включенный MCP-сервер или подключенная база знаний.
2. Нажмите `Запустить`.
3. Выберите `Add to LM Studio`.
4. Подтвердите открытие deeplink в LM Studio, когда ОС покажет запрос.

## Сборка Из Исходников

Требования:
- Go `1.26+`
- Node.js и npm

Сборка:

```bash
npm --prefix html install
npm --prefix html run build
go build -o MCPBox .
```

Запуск из исходников:

```bash
go run .
```

Порт по умолчанию: `38180`

## Примечания

- По умолчанию MCPBox использует локальную SQLite-базу.
- Текущая реализация Базы знаний / RAG использует локальный полнотекстовый поиск через Bleve. На этом этапе embedding-индексы не строятся и не требуются.
- Поддержка Docker runtime в `1.2.1` пока сделана как MVP. Продвинутые сценарии вроде compose-оркестрации, кастомных сетей и preset volumes еще не реализованы полностью.
- Flow `go_install` в `1.2.2` предполагает, что интеграцию можно установить через `go install module/path@version` и выдать как конкретный бинарник entry point.
- Маскировка секретов работает в UI и в catalog install flow. Уже существующие ручные серверы, которые передают секреты прямо в аргументах команды, лучше перевести на env-переменные для полной безопасности на уровне process list.
- Будущие возможности `Pro` вынесены в `PRO-ROADMAP.md` и не являются частью текущей реализации `1.2.2`.
- Кнопка запуска Ollama показывается только если `ollama` установлена на компьютере.
- Inspection доступен только для локальных `stdio` серверов.
