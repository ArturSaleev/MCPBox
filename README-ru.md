# MCPBox

MCPBox — это control plane на Go для MCP-серверов. Он позволяет группировать локальные и удалённые MCP-backend'ы по проектам, смотреть что они публикуют, отслеживать трафик и отдавать один project URL для Claude, Cursor, Codex, LM Studio и локальных сценариев с Ollama.

## Зачем нужен MCPBox

Когда MCP-серверов становится много, всё быстро превращается в набор JSON-конфигов, терминалов и локальных костылей. MCPBox собирает это в один бинарник и одну встроенную панель управления.

Основные возможности:
- Организация MCP-серверов по проектам
- Единый project endpoint `/mcp/{project_token}`, который агрегирует все включённые серверы проекта
- Live inspection локальных `stdio` серверов: `tools`, `resources`, `prompts` и соседний README
- Health-check при создании, редактировании, ручной проверке и запуске локального сервера
- Audit log для MCP-трафика и управляющих действий
- Пауза проекта и включение или отключение отдельных серверов
- Встроенный Market / Catalog для установки интеграций в проект
- Запуск локального `ollama + MCPBox` в один клик через встроенный `mcphost/sdk`
- Один бинарный файл со встроенным React UI и локальной SQLite-базой

## Что нового в 1.1.1

- Исправлен запуск Ollama на Windows: встроенная кнопка `Launch Ollama` теперь корректно стартует через отдельный PowerShell-сценарий
- Надёжнее обработка команд на Windows: пути с кавычками и пробелами больше не ломают запуск
- Исправлен запуск терминала на Windows: чат-сессия теперь открывается в рабочей директории проекта
- Добавлено автоматическое восстановление на Windows: если Ollama daemon ещё не поднят, MCPBox сам запускает `ollama serve` перед открытием чата

## Что нового было в 1.1.0

- Встроенная поддержка Ollama: локальный чат с MCP можно запускать прямо из UI без отдельной установки `mcphost`
- Агрегированный project endpoint: включённые серверы проекта доступны через один и тот же MCP URL
- Улучшенный автозапуск проекта: если в проекте есть хотя бы один включённый `stdio` сервер с `auto_start=true`, MCPBox запускает все включённые `stdio` серверы этого проекта
- Более аккуратная обработка Filesystem MCP: типовые informational stderr-сообщения больше не выглядят как ошибки доступа
- Новая страница Market и catalog flow: поиск интеграций, компактный sync, одна колонка карточек и более собранные действия

## Быстрый старт

1. Скачайте бинарник для своей ОС из последнего релиза или соберите проект из исходников.
2. Запустите `MCPBox`.
3. Откройте `http://127.0.0.1:38180/`, если браузер не открылся автоматически.
4. Создайте проект.
5. Добавьте локальные `stdio` серверы или удалённые `HTTP streaming` серверы.
6. Скопируйте project endpoint из UI и подключите AI-клиент к `/mcp/{project_token}`.

Для локального тестирования через Ollama:
1. Убедитесь, что `ollama` установлена.
2. Откройте проект, в котором есть хотя бы один включённый MCP-сервер.
3. Выберите локальную модель Ollama в UI.
4. Нажмите `Launch Ollama`.

## Сборка из исходников

Требования:
- Go `1.26+`
- Node.js и npm

Сборка:

```bash
npm --prefix html install
npm --prefix html run build
go build -o MCPBox .
```

Запуск из исходников:

```bash
go run .
```

Порт по умолчанию: `38180`

## Примечания

- По умолчанию MCPBox использует локальную SQLite-базу.
- Кнопка запуска Ollama показывается только если `ollama` установлена на компьютере.
- Inspection доступен только для локальных `stdio` серверов.
