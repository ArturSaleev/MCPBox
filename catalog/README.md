# Skills catalog sources

`skills-sources.txt` is the editable list used to refresh the static Skills catalog. It contains repositories discovered from public directory pages and the original OpenAI source.

`skills-pages/` holds local browser-exported public HTML pages. It is intentionally ignored by Git. The optional ready-to-use local parser bundle includes a copy as `pages/`.

Usage, error handling and publication instructions: [parser documentation](../cmd/skills-catalog/README.md).
