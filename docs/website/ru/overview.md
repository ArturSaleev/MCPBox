# MCPBox

[Оглавление](README.md) | [English](../en/overview.md)

MCPBox — административный control plane для AI-проектов и MCP-интеграций. Он помогает настраивать проекты, управлять доступом, публиковать подключения к инструментам и работать с корпоративными интеграциями в едином интерфейсе.

Продукт рассчитан на закрытые и on-premises-развёртывания. MCPBox работает как отдельный сервис и содержит веб-интерфейс администрирования и MCP endpoints проектов.

## Возможности MCPBox

- управление AI-проектами и MCP-подключениями;
- Администрирование: локальные пользователи, роли, сессии и токены доступа;
- отдельный MCP endpoint для каждого проекта;
- опциональный единый вход через любого OpenID Connect (OIDC) провайдера;
- интеграция с RagBox для баз знаний и поиска;
- audit logs, аналитика и настройка хранилищ.

MCPBox хранит конфигурацию проектов и опубликованные tool manifests. Он участвует в контуре контроля доступа, но не заменяет авторизацию в целевой бизнес-системе: окончательное решение о доступе к данным или действию должно приниматься системой-владельцем.

## Адреса по умолчанию

| Поверхность | Адрес по умолчанию |
| --- | --- |
| интерфейс администрирования администрирования | `http://127.0.0.1:38181/` |
| MCP endpoint проекта | `http://<server>:38182/mcp/<project-token>` |

Интерфейс администрирования по умолчанию слушает только localhost. MCP listener по умолчанию привязан ко всем сетевым интерфейсам; публикуйте его наружу только через необходимые сетевые ограничения, TLS и аутентификацию.

## Типовой порядок развёртывания

1. Скачайте и распакуйте MCPBox на сервере, где он будет работать.
2. Создайте первого локального администратора.
3. Запустите сервис и войдите в интерфейс администрирования.
4. Создайте проекты и настройте требуемые MCP servers и опциональные интеграции.

Подробности приведены в разделе [Установка и настройка](./installation.md).
