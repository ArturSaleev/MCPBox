# CLI

[Оглавление](README.md) | [English](../en/cli.md)

Встроенный реестр CLI позволяет открыть проекту выбранные операции локальных программ через MCP. Это отдельный механизм от установки MCP-серверов в Marketplace.

1. Установите доверенную программу и убедитесь, что она доступна служебной учётной записи MCPBox.
2. На странице CLI создайте запись или синхронизируйте каталог. Синхронизация ищет бинарники через PATH; она не устанавливает и не запускает программы.
3. Проверьте точные операции и допустимые наборы аргументов. Дополнительные аргументы по умолчанию запрещены.
4. Подключите запись на вкладке CLI проекта. Там же настройте **«Рабочие папки CLI для этого проекта»**: добавьте абсолютные пути на хосте либо явно выберите **«Все папки»** и сохраните.
5. Проверьте `cli_list`, `cli_describe`, затем разрешённый вызов `cli_execute` через MCP-клиент.

Например, для Git разрешите `status` и `log`; для `log` можно отдельно разрешить полный набор аргументов `["-n", "5"]`. Это не разрешает произвольные аргументы или shell-строку.

Программы выполняются без оболочки, в заданном каталоге проекта (или отдельном временном каталоге) и с ограниченным окружением, timeout и объёмом вывода. Стандартные пределы — 30 секунд и 1 MiB общего stdout/stderr. Это административный allowlist, а не изоляция ОС; разрешённая операция может изменять файлы или обращаться к сети.

Отключение записи или удаление связи блокирует следующие вызовы, но не отменяет уже запущенный процесс. Проект только с CLI также может публиковать MCP endpoint.

[Точная схема, API, ограничения и каталог](../../CLI.md).

Рабочая директория MCP-сервера и путь FilesSystemMCP независимы от каталога CLI проекта. Только `ssh`/`ssh.exe` дополнительно получает HOME и SSH_AUTH_SOCK служебной учётной записи. Заранее настройте для неё `BatchMode yes`, ключи и known_hosts; проверка ключей хоста остаётся включённой. Регистрируйте каждую полную удалённую команду как точный набор аргументов, например `["docker ps"]` для операции `mcpbox-linux`. Удалённая оболочка может интерпретировать команды SSH.

Временный каталог CLI удаляется после выполнения. Файлы, нужные следующим вызовам, сохраняйте в явно настроенном постоянном месте. Если заданный путь проекта отсутствует или указывает на файл, запуск отклоняется.

## Выбор рабочей папки

Настройки папок принадлежат проекту и действуют для всех его CLI. Разрешённая папка включает подкаталоги; режим «Все папки» разрешает любую существующую папку, доступную учётной записи MCPBox. Это выбор рабочей папки, а не изоляция файловой системы. Права FilesSystemMCP и рабочие папки MCP-серверов задаются отдельно.

Получите `directory_policy` через `cli_describe`, затем передайте абсолютный `working_directory` в `cli_execute`, например `{"cli":"git","command":"fetch","working_directory":"/srv/repos/app"}`. Операция и аргументы по-прежнему должны быть разрешены. Относительные, отсутствующие и недопустимые папки отклоняются; перед проверкой вложенности разрешаются символические ссылки.

При сохранённом списке без указания папки используется его первый пункт, а при пустом списке — временная папка. В режиме «Все папки» используется `root_path`, а если он пуст — временная папка. Существующие проекты сохраняют прежнее поведение до сохранения политики папок. Временные папки удаляются после вызова. Сохранение настроек требует `pro:admin`.
