# Устранение неполадок: сначала простые проверки

[Оглавление](README.md) | [English](../en/troubleshooting.md)

Если что-то не работает, выполняйте проверки по порядку. Чаще всего причина — неверный URL, остановленный server или закрытый port.

## 1. MCPBox не запускается

| Что видно | Что сделать |
| --- | --- |
| Port already in use | Выберите другой admin/MCP port либо остановите процесс, занявший порт. |
| Нет прав на базу или файлы | Дайте сервисному пользователю MCPBox доступ read/write к папке приложения и базы знаний. |

## 2. Не открывается admin page

Убедитесь, что MCPBox запущен. На самом сервере откройте `http://127.0.0.1:38181/`. Если там всё работает, но с вашего компьютера страница недоступна, это нормально: admin UI приватный по умолчанию. Используйте VPN, SSH tunnel или одобренный reverse proxy, а не открывайте порт в интернет.

## 3. MCP-клиент не подключается

Проверьте MCP URL проекта вместе с project token. Затем убедитесь, что сервер включён и healthy в проекте. Для внешнего клиента проверьте HTTPS reverse proxy, firewall и certificate. Если включены bearer authentication или проверка identity через PolicyBox, у клиента должен быть правильный token.

Для OAuth-подключения ChatGPT проверьте поле `outcome` в **Logs**:

- `redirect_uri_mismatch` означает, что callback текущей настройки ChatGPT не совпадает с сохранённым. Пересоздайте OAuth-пользователя с callback из того же открытого окна ChatGPT.
- `no such table: project_oauth_clients` означает, что после обновления ещё работает старый процесс. Перезапустите MCPBox: при старте таблица будет создана или безопасно перенесена из прежнего имени с сохранением пользователей.

## 4. Не работает пакет Marketplace

Посмотрите server health error и Logs. Проверьте, что runtime пакета установлен на сервере MCPBox, credentials верны, а service account может выполнить команду. Удалите неудачный тестовый пакет до повторной попытки с другими credentials.

## 5. Поиск по базе знаний пустой или плохой

Убедитесь, что коллекция содержит поддерживаемые файлы и из них реально извлекается текст. Сканированным PDF часто нужен OCR до индексации. После изменения источников сделайте reindex. Несвязанные документы храните в отдельных коллекциях и задавайте конкретные вопросы с именами, датами и терминами.

## 6. Не сохраняется RagBox или PolicyBox

Проверьте, что base URL доступен именно с сервера MCPBox, а не только с вашего ноутбука. Проверьте tenant ID и tokens, затем status интеграции или runtime playground. Никогда не отправляйте token в публичный чат или общий screenshot.

## Что отправлять в поддержку

Отправьте версию продукта, ОС, время ошибки, относящуюся к делу запись log и описание действия. Сначала удалите passwords, bearer tokens, API keys и персональные данные.
