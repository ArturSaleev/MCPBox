for the next month. Public, unauthenticated GitHub REST API (60 requests/hour); no token
and no `gh` CLI were available in this environment.

**Reading the tables.** `—` means the value could not be obtained on this date, and each
case is explained in one line right below its table. A literal `0` is a real value returned
by the API (e.g. `forks_count`, `download_count`), not a placeholder for missing data.

## How to repeat

Run these in a normal shell next month. `gh` is preferred when it is installed and
authenticated; the `curl` variants need no token (60 requests/hour) except for traffic.

```bash
# Repository metadata: stars, forks, watchers, open issues + PRs, created, pushed, license, topics
gh api repos/ArturSaleev/MCPBox

# All releases, every page, with per-asset download counts
gh api repos/ArturSaleev/MCPBox/releases --paginate

# Total downloads across all releases and assets
gh api repos/ArturSaleev/MCPBox/releases --paginate \
  | jq '[.[].assets[].download_count] | add'

# Downloads per platform (file name minus the MCPBox- prefix and .exe suffix)
gh api repos/ArturSaleev/MCPBox/releases --paginate \
  | jq -r '[.[].assets[] | {p: (.name | sub("^MCPBox-"; "") | sub("\\.exe$"; "")), d: .download_count}]
           | group_by(.p)
           | map({platform: .[0].p, downloads: (map(.d) | add)})
           | sort_by(-.downloads)
           | .[] | "\(.platform)\t\(.downloads)"'

# Latest release only
gh api repos/ArturSaleev/MCPBox/releases/latest

# Traffic — owner rights required, last 14 days only
gh api repos/ArturSaleev/MCPBox/traffic/views
gh api repos/ArturSaleev/MCPBox/traffic/clones
```

Without `gh`, the same data over plain `curl`, walking the release pages explicitly:

```bash
api() {
  curl -sS -H "Accept: application/vnd.github+json" \
            -H "User-Agent: mcpbox-baseline" "$1"
}

# Repository metadata
api https://api.github.com/repos/ArturSaleev/MCPBox

# All release pages, per asset: tag, published_at, file name, download_count
page=1
while :; do
  body=$(api "https://api.github.com/repos/ArturSaleev/MCPBox/releases?per_page=100&page=$page")
  echo "$body" | jq -r '.[] | .tag_name as $t | .published_at as $p
    | .assets[] | [$t, $p, .name, (.download_count|tostring)] | @tsv'
  [ "$(echo "$body" | jq 'length')" -lt 100 ] && break
  page=$((page + 1))
done

# Totals
api "https://api.github.com/repos/ArturSaleev/MCPBox/releases?per_page=100&page=1" \
  | jq '[.[].assets[].download_count] | add'

# Traffic (expect 401/403 without owner rights)
api https://api.github.com/repos/ArturSaleev/MCPBox/traffic/views
api https://api.github.com/repos/ArturSaleev/MCPBox/traffic/clones
```

Then create `docs/metrics/<YYYY-MM-DD>-baseline.md` with the same sections and compare
against this file, row by row.

## Commands executed for this snapshot

Exact commands, in order. `gh` was checked first and is not installed here; `curl` is
present but could not complete a TLS handshake in this sandbox, so the same public
endpoints were queried through Node.js `https` (OpenSSL, own trust store) with identical
headers and no credentials.

```powershell
# 1. Snapshot date — never typed by hand
Get-Date -Format "yyyy-MM-dd"
# -> 2026-10-21

# 2. Tooling
(Get-Command gh -ErrorAction SilentlyContinue).Source   # -> empty: gh is not installed
(Get-Command curl.exe).Source                           # -> C:\Windows\system32\curl.exe

# 3. curl attempt (failed at the TLS layer, before reaching GitHub)
curl.exe -sS -H "Accept: application/vnd.github+json" https://api.github.com/repos/ArturSaleev/MCPBox
# -> curl: (35) schannel: AcquireCredentialsHandle failed: SEC_E_NO_CREDENTIALS

# 4. Invoke-RestMethod attempt (also failed)
Invoke-RestMethod -Uri https://api.github.com/repos/ArturSaleev/MCPBox
# -> WebException: base connection closed

# 5. Working fallback: Node.js https, GET only, no token
node collect.js   # hits the endpoints listed below, writes raw JSON
```

The `collect.js` above was a throwaway file in the system temp directory; nothing was added
to the repository apart from this markdown file, and no token, cookie or key was used at any
point.

Endpoints requested, in this order (8 core requests, all unauthenticated):

1. `https://api.github.com/repos/ArturSaleev/MCPBox`
2. `https://api.github.com/repos/ArturSaleev/MCPBox/releases?per_page=100` (single page
   returned 12 releases, no `Link: rel="next"`, so the listing is complete)
3. `https://api.github.com/repos/ArturSaleev/MCPBox/releases/latest`
4. `https://api.github.com/repos/ArturSaleev/MCPBox/issues?state=open&per_page=100`
5. `https://api.github.com/repos/ArturSaleev/MCPBox/pulls?state=open&per_page=100`
6. `https://api.github.com/repos/ArturSaleev/MCPBox/traffic/views` → `401`
7. `https://api.github.com/repos/ArturSaleev/MCPBox/traffic/clones` → `401`
8. `https://api.github.com/rate_limit` → `core: 53/60 remaining`

The Node fallback in full, for environments where `curl`'s schannel backend is
unavailable:

```js
const https = require("https");

const get = (url) =>
  new Promise((resolve) => {
    https.get(
      url,
      { headers: { "User-Agent": "mcpbox-baseline", Accept: "application/vnd.github+json" } },
      (res) => {
        let d = "";
        res.on("data", (c) => (d += c));
        res.on("end", () =>
          resolve({ status: res.statusCode, link: res.headers.link, body: d })
        );
      }
    ).on("error", (e) => resolve({ status: 0, error: e.message }));
  });

const base = "https://api.github.com/repos/ArturSaleev/MCPBox";

(async () => {
  const repo = await get(base);
  console.log(repo.status, JSON.parse(repo.body).stargazers_count); // 200 9

  let url = `${base}/releases?per_page=100`;
  let total = 0;
  while (url) {
    const r = await get(url);
    for (const rel of JSON.parse(r.body)) {
      for (const a of rel.assets) {
        total += a.download_count;
        console.log(rel.tag_name, a.name, a.download_count);
      }
    }
    const next = r.link && r.link.match(/<([^>]+)>;\s*rel="next"/);
    url = next ? next[1] : null;
  }
  console.log("TOTAL", total); // 58

  for (const p of ["traffic/views", "traffic/clones"]) {
    const t = await get(`${base}/${p}`);
    console.log(p, t.status, t.body); // 401 without owner rights
  }
})();
```
