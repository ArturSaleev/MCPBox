# PolicyBox: прежняя интеграция

Интеграция удалена из текущих исходников MCPBox для планируемого v1.3.1. Опубликованный v1.3.0 сохраняет старое поведение. Прежний runtime flow больше нельзя включить через настройки.

Используйте [инструкцию перехода с сохранением данных](website/ru/policybox-migration.md) / [English migration guide](website/en/policybox-migration.md). Историческая реализация доступна в Git-истории этого файла и тега v1.3.0.
